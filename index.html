  • Python
  • Tkinter
  • JSON
  • unittest

Architecture

The project separates the user interface, application logic, and data persistence. The CLI and Tkinter GUI share the same backend logic.

  1. gui.py
  2. backend.py
  3. main.py
  4. data.json

  • Salted and hashed passwords using PBKDF2-HMAC-SHA256
  • Friend request system
  • Accept and decline friend requests
  • Block and unblock users
  • Send and receive private notes
  • Read/unread message tracking
  • Important/flagged notes
  • Reply to notes
  • Per-user note deletion
  • Tkinter desktop GUI
  • Command-line interface
  • Local JSON data storage
  • Unit testing with unittest
